## About

I work at the intersection of experimentation, applied ML, and LLM systems — designing statistical methodologies that make previously untestable products testable, building production ML pipelines end to end, and shipping LLM-based tools that replace manual analyst work. My background is in data analytics inside a large financial services chatbot organization; the projects below show the range, from classical statistics to production ML to hands-on deep learning research.

**Currently:** building an autonomous agent that designs and analyzes A/B tests — combining CUPED variance reduction, uplift modeling, and LLM tool-calling orchestration. [Follow along here.](https://github.com/vmirchu-git/ab-testing-agent)
